Abstract

Gelmat is an ontology for sol-gel materials. It extends the Polymat domain ontology with classes for sol-gel synthesis processes, gel characterisation methods, drying routes, laboratory equipment, process parameters, and material properties. It enables semantic description and formal documentation of sol-gel and aerogel research workflows, covering silica, organosilica, organic, carbon, and composite sol-gel derived materials.

Gelmat: Description back to ToC

Gelmat is an ontology for sol-gel materials. It extends the Polymat ontology (Dembska, Held, Schindler; DLR/Hereon) with classes for sol-gel synthesis routes, gel types, surface modification, drying methods, characterisation methods, process parameters, and material properties. Covers all major sol-gel derived material classes including silica, organosilica, organic, carbon, and composite aerogels.
